FAQ

Why do I need Discord?

Discord provides your account identity. Your Jnkie key must be associated with the same Discord account before your private config area is unlocked.

Can other users see my configs?

No public config list is provided. Database rules and private file storage restrict access to your own account. Download links are short-lived.

Which files can I upload?

Only non-empty .txt files up to 1 MB.
